# PinHarbor brand

## Name

**PinHarbor** describes map pins being collected into a reliable local destination. It avoids names already in active software use such as LeadLoom, MapLoom, Prospect Forge, and ScoutGrid.

## Product descriptor

Local lead discovery

## Logo

Primary raster asset:

`web/static/img/pinharbor-logo.png`

The mark combines a map pin, beacon dot, and signal arcs. It has a transparent background and is designed for dark and light surfaces.

## Palette

| Token | Hex | Role |
| --- | --- | --- |
| Harbor navy | `#07131B` | Default canvas |
| Sea-glass green | `#24D6A1` | Primary action/live status |
| Signal cyan | `#3ABFF8` | Secondary action/progress |
| Beacon coral | `#FF8A65` | Warnings/destructive accent |

## Theme rules

- Dark mode is the default.
- Light mode must preserve semantic color meaning.
- Do not place the logo inside another colored square.
- Use coral sparingly.
- Green indicates healthy/live/completed states.
- Cyan supports navigation, progress, and secondary actions.
